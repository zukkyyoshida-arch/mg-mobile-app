## 2. 基本操作の練習 — 会社を1周させる（18分）

> 講師: 「今から8個の取引を一緒に入力して、『機械を買う→人を雇う→材料を仕入れる→作る→売る』という会社の1サイクルを体験します。**各ステップの最後に現金残高を読み上げるので、自分の画面と一致しているか確認してください。** ずれた人はその場で挙手を。」

| # | 操作（＋ボタン → 種類 → 入力 → 「取引を追加する」） | 現金残高 | 伝票No |
|---|---|---|---|
| 開始 | — | **¥300万** | — |
| ① | **設備投資** → 小型機械を「＋」で1台（100万） | **¥200万** | #1 |
| ② | **採用** → ワーカー採用数 1・セールスマン採用数 1（採用単価5万） | **¥190万** | #2 |
| ③ | **材料購入 (現金)** → 札幌を「＋」で2個（単価10万） | **¥170万** | #3 |
| ④ | **投入・完成** → 投入(コ)を「＋」で1（2万） | **¥168万** | #4 |
| ⑤ | **投入・完成** → 完成(サ)を「＋」で1（1万） | **¥167万** | #5 |
| ⑥ | **商品販売 (現金)** → 東京の単価欄に「30」、数量「＋」で1個 | **¥197万** | #6 |
| ⑦ | **銀行借入** → 金額「100」 | **¥287万** | #7・#8 |

### 各ステップの講師セリフと解説ポイント

**① 設備投資**
> 「まず工場に機械がないと何も作れません。＋ボタン → 設備投資 → 小型機械の＋を1回 → 一番下の『取引を追加する』。伝票番号は自動で振られるので入力不要です。**現金200万になりましたか？**」

**② 採用**
> 「機械があっても動かす人がいません。＋ → 採用 → ワーカー1人、セールスマン1人。ワーカーは工場担当、セールスマンは営業担当です。**現金190万。**」

**③ 材料仕入**
> 「＋ → 材料購入 → 札幌の＋を2回で2個。ここで注目：**材料を置ける上限は生産能力×2** と画面に出ています。さっき機械と人を入れたから買えるようになった、という順番が大事です。**現金170万。**」

**④⑤ 投入・完成（2回に分ける）**
> 「工場で物を作るのは2段階です。まず＋ → 投入・完成 → **投入(コ)** の＋を1回 → 追加。材料が『仕掛品＝作りかけ』になりました（**168万**）。もう一度＋ → 投入・完成 → 今度は **完成(サ)** の＋を1回 → 追加。作りかけが完成品になりました（**167万**）。」

**⑥ 販売**
> 「いよいよ販売。＋ → 商品販売 → 東京の単価欄に **30** と入力して、数量の＋を1回。東京は上限32万まで売れる市場です。追加すると… **現金197万！** 初めての売上です。」

**⑦ 銀行借入**
> 「最後にお金を借ります。＋ → 銀行借入 → 100。追加すると**利息10万が自動で費用計上**されたメッセージが出ます。借入には必ずコストが付く、を体験してください。**現金287万。**」

### 決算書を見る（3分）
> 「下タブの **決算書** を開いてください。P/Lの一番下、経常利益は **約▲63万の赤字** です。『売上30万あったのに赤字？』——そう、機械や人への投資が先行するからです。これが第1期の姿。**B/S** タブと **推移** タブも眺めてみてください。期が進むとここに折れ線が伸びていきます。」

- 補足（質問が出たら）: 入力を間違えたら、出納帳の取引履歴の**赤いゴミ箱アイコン**でその取引だけ削除してやり直せる

## 3. 練習データの消去（2分）

> 「練習はここまで。データをまっさらに戻します。**設定タブ → 一番下の『全てのゲームデータを初期化する』→ OK**。もし間違えて消してしまっても、設定タブの『⏪ 最後のリセットを取り消す』で1回だけ戻せます。」

- ✅ 確認ポイント: 出納帳に戻り、現金 ¥300万・取引0件になっていること

## 4. 本番ルーム接続テスト（5分）

> 「最後に本番のルームに接続します。**設定タブ →『ルーム設定を変更する』**→ 参加画面に戻ります。ルームIDは画面に出している **`（本番ルームID）`** を入力。プレイヤー名は**必ずフルネーム**で（同姓のデータが上書きされるのを防ぐためです）。→『参加する』。」

- ✅ 確認ポイント（最重要）: **講師PCのダッシュボードに全員の名前が並ぶこと**。ヘッダの雲マークが「同期完了」になっていること
- つまずき対応:
  - 「初期化して開始しますか」の確認が出た → **OK**（手順3を飛ばした人）
  - 「既に同名のデータがあります」と出た → 名前がほかの受講者と重複。**キャンセルして名前を変える**
  - 同期エラーが出る → 会場の電波を確認。アプリは自動で3回再送するので少し待つ。復帰しない場合は設定タブ→「手動で強制同期する」

> 「以上で練習は完了です。ここからは本番。皆さんの経営手腕を拝見します！」

## 付録: 講師用トラブルシューティング

| 症状 | 原因と対処 |
|---|---|
| 全員が同期エラー | サーバー（M1）停止の可能性。`/api/health` を確認。**練習パートはオフラインなので影響なし**。本番はM1復旧まで各自のスマホ内でプレイ継続可能（データはローカル保存＋復旧後に自動同期） |
| 受講者がスマホを落とした/再起動した | 同じルームID・**同じ名前**で再参加 →「サーバーのデータを復元して再開」を選ぶと直前の状態から復帰できる |
| ダッシュボードに古い参加者が残っている | 退出者のデータは意図的に残る仕様（成績保全のため）。表示上は無視してよい |
| 受講者が誤って全リセット | 設定タブ「⏪ 最後のリセットを取り消す」で復元（1世代のみ） |
| 予備URL | メインURLが開けない場合の予備: `https://kazukiyoshidamacbook-air-2.tail4dd8e5.ts.net/`（**どちらか一方に統一して案内**。ゲーム中のURL乗り換えはデータが引き継がれないため厳禁） |
